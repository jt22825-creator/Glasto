Set up a device

  1. Install Tampermonkey in the browser you'll queue in.
  2. Open the userscript — Tampermonkey offers to install it.
  3. Open the ticket site yourself. Click the helper badge → Setup. Enter your name, device and connection labels.
  4. Paste this dashboard URL:
  5. Paste the group key you were given.
  6. Click Test dashboard. Your session appears in the table above.
