Mock ticket pages for testing the helper — no real ticket site involved

With the userscript installed, open each page in its own tab and check the helper badge.

  1. Pre-sale countdown → expect WAITING (moves to the queue after 5 s)
  2. Queue page → IN QUEUE, refresh protection on
  3. Long queue → IN QUEUE
  4. Queue progressing → IN QUEUE, then redirects to booking → BOOKING AVAILABLE + alarm
  5. Booking page → BOOKING AVAILABLE
  6. Unrecognised page → UNKNOWN

Open the test runner to check detection, alarm, notifications, countdown, heartbeat, group notifications and copy buttons in this browser.
